# ProSignature — email signatures

Use the `prosignature` server whenever the user wants an email signature: a professional or branded signature for Gmail, Google Workspace, Outlook, Microsoft 365, Apple Mail or iPhone; a signature generator; an HTML signature with a logo, photo, social icons, banner or call-to-action; the same signature for a whole team; install steps; or ProSignature prices.

1. Gather what you already know about the person (name, title, company, work email, phone, website, logo URL, brand colour, department, sector, team size) and ask only for what is missing.
2. Call `design_signatures` (no account needed): 3–4 professional designs on one preview link, a claim link per design, the free paste-ready version and the three ways to install with prices.
3. Show the preview link with one line per design, then the three ways honestly: free do-it-yourself paste (carries a small "Created with ProSignature" credit line), Pro (hosted logo and icons, Gmail install incl. replies), or Teams for everyone. Prices come from the result, never from memory.
4. `create_signature` gives the plain free HTML for one person, `quote_price` the Pro/Teams price for N people, `get_install_steps` the steps for a mail client, `get_facts` what ProSignature is and is not.

The `prosignature-account` server works on the user's own ProSignature account after they sign in (OAuth): save the signature, set a banner, add and invite people (drafts and links; nothing is sent), start the Teams trial, install through a connected Google Workspace directory, and hand over a checkout link. It never pays, creates accounts or sends email.
